# 종가 스코어링 (웹앱)

매일 종가로 국내 주식 전 종목에 점수를 매기고, 추천 종목·매수/매도 할 일·자산(투자원금, 손익)을 관리하는 앱입니다.

- 평일 15:45, 16:30(한국 시간)에 GitHub Actions가 자동으로 계산해 GitHub Pages에 올립니다.
- 폰에서는 앱 주소를 열고 Chrome 메뉴의 **홈 화면에 추가(앱 설치)** 를 누르면 됩니다.
- 앱의 🔄 버튼: '최신 결과 불러오기'는 바로, '지금 다시 계산하기'는 2~3분 걸립니다(GitHub 키 필요).
- 매매 기록·입출금 장부는 폰 브라우저에만 저장됩니다. 저장소에는 시세·점수만 올라갑니다.

※ 투자 권유가 아닌 참고 자료입니다.
